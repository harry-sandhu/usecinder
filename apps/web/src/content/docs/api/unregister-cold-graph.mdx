Use `unregisterColdGraph()` when a cold catalog should no longer participate in hybrid graph construction.

## Example

```ts
Cinder.unregisterColdGraph('docs-catalog');
```

## When to use it

- hot-reload or teardown paths
- feature areas that mount and unmount separately
- tests that need precise graph setup/cleanup
