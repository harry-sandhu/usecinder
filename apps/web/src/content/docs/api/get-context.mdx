Use `getContext()` when you want to inspect the current injected runtime context explicitly.

## Example

```ts
const context = await Cinder.getContext();
console.log(context);
```

## What it returns

A promise that resolves to a normalized plain object.

If no provider is installed, it resolves to `{}`.

## Why it helps

Use it for:

- debugging context injection
- verifying async provider behavior
- integration tests around context-aware commands
