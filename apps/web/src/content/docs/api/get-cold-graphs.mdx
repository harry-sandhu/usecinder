Use `getColdGraphs()` when you want to inspect what durable graph catalogs are currently registered.

## Example

```ts
const catalogs = Cinder.getColdGraphs();
console.log(catalogs.map((catalog) => catalog.id));
```

## Why it helps

This is useful for:

- debugging hybrid graph setup
- verifying whole-site semantic catalogs were registered
- integration tests
- runtime inspection in dogfooding environments
