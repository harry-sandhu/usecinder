Use `offTranscript()` to remove a transcript handler that was registered with `Cinder.onTranscript()`.

## Example

```ts
const handler = (event) => {
  console.log(event.transcript);
};

Cinder.onTranscript(handler);
Cinder.offTranscript(handler);
```
