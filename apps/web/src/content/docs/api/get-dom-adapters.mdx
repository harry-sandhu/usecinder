Use `getDomAdapters()` when you want to inspect the current DOM adapter registry.

## Example

```ts
const adapters = Cinder.getDomAdapters();
console.log(adapters.map((adapter) => adapter.id));
```

## Why it helps

This is mostly useful for:

- debugging custom control integration
- verifying adapter registration in tests
- understanding which adapters are active in the current app shell
