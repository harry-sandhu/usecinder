Use `onReflex()` when you want to observe or augment user-facing response behavior after a command completes.

## Example

```ts
Cinder.onReflex((result) => {
  console.log(result.kind, result.message);
});
```

## What the handler receives

A `CinderReflexResult` containing:

- `ok`
- `kind`
- `message`
- `spoken`
- `intent`
- optional `dispatch`

## When to use it

- analytics or logging
- custom UI notifications
- integration tests
- application-side reaction to reflex outcomes
