Use `onSpeechError()` when you want to observe speech failures explicitly.

## Example

```ts
Cinder.onSpeechError((error) => {
  console.error(error.code, error.message);
});
```

## What the handler receives

A speech error object containing:

- `code`
- `message`

## Why it matters

Speech support depends on browser APIs and environment support. Error hooks are the clean way to surface unsupported or failed speech behavior to the application.
