Use `unregisterRoute()` to remove a previously registered route definition.

## Example

```ts
Cinder.unregisterRoute('reports');
```

## When to use it

- cleaning up SPA integration state
- swapping route definitions dynamically
- removing temporary route hooks in tests or embedded surfaces
