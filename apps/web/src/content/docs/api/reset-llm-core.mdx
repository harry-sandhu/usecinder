Use `resetLlmCore()` to undo a `setLlmCore()` call and go back to the default behavior.

## Example

```ts
Cinder.resetLlmCore();
```

This restores the built-in HTTP fallback core and resets `requiresNetwork` back to its default (`true`) - the exact state the runtime starts in before any `setLlmCore()` call.
