Use `getRoutes()` when you want to inspect the current route registry.

## Example

```ts
const routes = Cinder.getRoutes();
console.log(routes);
```

## What it returns

An array of registered `CinderRouteDefinition` values.

This is useful for:

- debugging route activation strategy
- verifying route registration happened as expected
- integration tests
