Use `say()` when you want explicit speech synthesis outside the full reflex pipeline.

## Example

```ts
const spoken = Cinder.say('Reports are ready.');
console.log(spoken);
```

## What it returns

- `true` when browser speech synthesis was available and speech was started
- `false` when the environment does not support speech synthesis

## Typical use

Most integrations should let `respond()` or `run()` decide when to speak. Use `say()` directly only when you want explicit application-side speech output.
