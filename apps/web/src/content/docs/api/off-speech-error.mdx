Use `offSpeechError()` to remove a handler that was registered with `Cinder.onSpeechError()`.

## Example

```ts
const handler = (error) => {
  console.error(error.message);
};

Cinder.onSpeechError(handler);
Cinder.offSpeechError(handler);
```
