Use `off()` to remove a runtime event handler that was previously registered with `Cinder.on()`.

## Example

```ts
const handler = (payload) => {
  console.log(payload);
};

Cinder.on('dispatch:end', handler);
Cinder.off('dispatch:end', handler);
```

## Important note

Pass the same handler reference you originally registered.
