Use `onTranscript()` when you want direct access to speech transcript events.

## Example

```ts
Cinder.onTranscript((event) => {
  console.log(event.transcript, event.isFinal);
});
```

## What the handler receives

A transcript event containing:

- `transcript`
- `isFinal`
- `timestamp`

## When to use it

- custom voice UX
- manual transcript display
- integrations using `listen({ autoRun: false })`
