Use `unbind()` when a route, action, field, filter, or output binding should no longer be active.

## Example

```ts
const handler = () => {
  console.log('search action triggered');
};

Cinder.bind('action', 'search', handler);
Cinder.unbind('action', 'search');
```

## Parameters

- binding type: `route`, `action`, `field`, `filter`, or `output`
- key: the semantic key that was bound

## When to use it

- cleaning up app-specific integration state
- replacing one binding strategy with another
- preventing bindings from surviving longer than the page or feature region they belong to
