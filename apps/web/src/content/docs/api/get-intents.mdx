Use `getIntents()` when you want to inspect the custom matcher registry.

## Example

```ts
const matchers = Cinder.getIntents();
console.log(matchers.map((matcher) => matcher.id));
```

## Why it helps

This is mostly useful for:

- debugging local resolution extensions
- test assertions
- confirming domain presets or custom matchers were installed
