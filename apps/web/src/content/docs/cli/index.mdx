`@cinder/cli` closes the loop between "install Cinder" and "every real page is actually tagged well" - instead of a developer running each tagging-checklist audit by hand, one command crawls the real app and writes a single consolidated report a coding agent can act on.

## Install

```bash
npm install --save-dev @cinder/cli
```

This installs a `cinder` binary. It depends on `playwright` and `jsdom` - real, dev-time-only dependencies, kept separate from the dependency-light core `usecinder` SDK.

## This only reads your app

`cinder integrate` never edits your source files itself. Deciding which findings are real and applying them is left to you and your coding agent - the same judgment call every other Cinder audit tool already requires.
